# loans-personal-application
Personal loan apply form for all loan brands, connected to the LMS.

Built with [Astro](https://astro.build) and hosted on Vercel. Needs Node 22.23.4 or newer.

```bash
npm install
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Runs the site at http://localhost:4321 |
| `npm run build` | Builds the site for hosting |
| `npm run check` | Checks the code for errors |

This repo is public, so secrets must never go in the code. They live in Vercel's settings.
